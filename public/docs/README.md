# Carpeta de Documentos PDF y Archivos Digitales — Casa de la Memoria Cumbal

Esta carpeta `public/docs/` alberga los archivos PDF locales servidos directamente por Vercel / Next.js.

## 📄 Estructura de Archivos Locales:
- `/public/docs/cumbe-renaciente.pdf`: Archivo PDF digitalizado del libro **Cumbe renaciente. Una historia etnográfica andina** (Joanne Rappaport, ICANH).

## 💡 Cómo agregar el PDF definitivo:
1. Copia tu archivo PDF original a esta carpeta con el nombre exacto: `cumbe-renaciente.pdf`
2. El archivo será servido automáticamente por Vercel en la URL: `https://casa-memoria-web.vercel.app/docs/cumbe-renaciente.pdf`
